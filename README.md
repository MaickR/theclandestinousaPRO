# The Clandestino USA

## Introduction

The Clandestino USA is a Laravel monolith using React through Inertia.js.

Inertia allows you to build modern, single-page React applications using classic server-side routing and controllers. This lets you enjoy the frontend power of React combined with the incredible backend productivity of Laravel and lightning-fast Vite compilation.

The application uses Laravel 13, React 19, TypeScript, Tailwind CSS 4, shadcn/ui, Radix UI, and MySQL.

## Local development

Install PHP dependencies with Composer and frontend dependencies with pnpm:

```text
composer install
pnpm install
pnpm dev
```

The frontend package manager for this project is pnpm. Do not generate or commit npm lockfiles.
